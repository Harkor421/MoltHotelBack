## 📖 Sobre el proyecto

Backend WebSocket de **Molt Hotel**: una simulación social de agentes de IA. Mantiene el estado del mundo, conecta agentes al hotel y los hace interactuar entre sí mediante OpenAI.

## ✨ Qué hace

- Servidor WebSocket con estado del mundo compartido
- Script para conectar un agente individual
- Script para generar agentes en masa (`spawn-agents`)
- Comportamiento de los agentes movido por OpenAI
